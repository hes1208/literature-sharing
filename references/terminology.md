# 术语核对 Terminology

以下是写作时的核对提醒，**不是强制统一词表**。先结合论文定义，再参考该学科可靠的一手资料；无法确定且影响结论时指出待核实项。首次出现可给中英文和缩写，随后保持一致。

These are contextual checks, not universal translations. Use the paper's own definition and appropriate primary disciplinary sources when needed.

| English | 常见中文 | 核对点 / Check |
| --- | --- | --- |
| technology adoption | 技术采用；技术采纳 | 不自动等同于跨国技术转移 |
| technology diffusion | 技术扩散 | 区分扩散速度与最终普及程度 |
| granularity | 技术粒度；规模与价格属性 | 必须说明编码方向；概念上的高粒度可能对应较小单元，指标却用单位价格对数 |
| material intensity | 材料强度 | 写清分母，例如千克/美元，不等于总材料使用量 |
| state capacity | 国家能力 | 与政府类型、治理质量不等同 |
| formative phase | 形成期 | 按创新/技术生命周期语境解释 |
| logistic function | 逻辑斯蒂函数 | 与logistic回归的研究用途有区别 |
| asymptote | 渐近线；渐近上限 | 是拟合参数，未必为已观测市场规模 |
| growth duration | 增长持续时间 | 交代采用水平区间，例如10%—90% |
| confidence interval | 置信区间 | 区别标准差、标准误和预测区间 |
| percentage point | 百分点 | 不译作相对变化百分比 |
| mitigation | 减缓；减排 | 气候目标和具体排放量语境不同 |
| sequestration | 固存；封存 | 土壤碳与工程储存语境不同 |
| feedstock | 原料；生产原料 | 不一律译作动物饲料 |
