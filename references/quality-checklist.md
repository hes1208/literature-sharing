# 交付检查 Quality checklist

## 科学内容 Scientific content

- [ ] 六项文献信息真实完整；作者、机构对应，DOI及在线发表时间正确。
- [ ] 摘要中文为完整翻译，术语、数值、单位、限制条件准确。
- [ ] 背景保留最重要的引言逻辑；目的与研究问题相符；字数在 300–450 字内。
- [ ] 各主要方法说明用途、信息来源、推导/估计逻辑和关键假设。
- [ ] 所有范围内公式有原文截图，各符号、下标、单位和条件均已解释。
- [ ] 所有范围内图表截图齐全；结果正文逐张引用，子图对应准确。
- [ ] 结果仅保留主要发现，方向、基准、时间和数量一致；字数在 800–1200 字内。
- [ ] 单变量与多变量、相关与因果、无显著证据与无影响不混淆。
- [ ] 讨论总结结论及逻辑；政策来自原文，没有杜撰独立结论章节。
- [ ] 英文摘要与可见原文一致，仅修复提取噪声。
- [ ] 发现的原文矛盾已校注，未将推断包装成原文事实。

## 三条硬性惯例 Hard conventions

- [ ] **表格全部为原文截图**：Word 中不存在由本人生成的表格对象（`doc.tables` 应为空或仅含版式用表），表体保持原文语言。
- [ ] 表名在截图上方、注释在截图下方；图名与注释在图下。
- [ ] **结果与讨论的子标题与原文逐条对应**：数量、顺序、含义一致，未新增“数据集概况”一类原文没有的小节。
- [ ] 全文正文（不含摘要译文与图表题注）在 2500–3500 字区间，未超 4200 字上限。

## 图像与排版 Images and layout

- [ ] 全部坐标轴、图例、子图字母、表边界（含表头与注释分隔线）和公式编号可见。
- [ ] 图片清晰、比例正确；未为塞入单页缩小到不可读。
- [ ] 无跨页孤立图注、空白页、标题悬空、重叠或缺字。
- [ ] 公式及解释、图表及题注相邻；长表续页保留“续表”标记及表头。
- [ ] 截图未带入原文版面的图表上下分隔细线。
- [ ] 最终 Word 已渲染，全部页图已逐页查看；改版后重新检查。

## 交付 Delivery

- [ ] 成稿位于用户指定目录，未覆盖已有稿。
- [ ] Word正文可编辑；最终链接为真实绝对路径。
- [ ] 临时渲染图、校对PDF和台账未混入最终交付。
- [ ] 尚未完成的内容或视觉检查如实说明，不声称已通过。

English: Verify metadata, full abstract fidelity, the introduction's logic, methods and all symbols, every in-scope screenshot, complete translated captions/notes and narrative citations, statistical interpretation, author-supported discussion/policy, and exact English abstract. Confirm that tables are screenshots with untranslated bodies, that Results/Discussion subheadings mirror the source one-to-one, and that prose stays inside the word budget. Inspect all final rendered pages. Mechanical validation never certifies scientific fidelity, caption placement or visual quality.
